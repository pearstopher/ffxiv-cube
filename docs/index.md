# Cube

Cube is a Dalamud plugin for Final Fantasy XIV that draws a window showing a cube of space around your
character, with nearby players as small labelled cubes.

This site is generated from the code. The **Code reference** is built from the XML doc comments on every
type and member (public, internal and private), and the comments explain why the code works the way it
does and which rule from the spec it implements. Each namespace page gives an overview of its part of the
plugin.

- **Code reference:** how the plugin works, straight from the code.
- **On GitHub:** the same reference as Markdown is in `docs/reference/` in the repository.
- **Articles:** the few things that can't live in code, such as the README and the development guide.
